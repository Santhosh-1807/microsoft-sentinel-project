# Microsoft Sentinel SOC Project

## Project Overview
This project demonstrates the use of Microsoft Sentinel as a SIEM
solution for security monitoring, threat detection and incident investigation.

## Objectives
- Configure Microsoft Sentinel
- Connect security data sources
- Collect security logs
- Create KQL queries
- Create analytics rules
- Generate security incidents
- Investigate alerts
- Monitor security events

## Technologies Used
- Microsoft Sentinel
- Microsoft Entra ID
- KQL
- Azure
- SIEM
- Security Monitoring

## Project Workflow

Data Source
     ↓
Microsoft Sentinel
     ↓
Log Analytics Workspace
     ↓
KQL Queries
     ↓
Analytics Rules
     ↓
Alerts / Incidents
     ↓
Investigation
